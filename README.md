Проект Чат-Сервер

Обзор

Это простое много-клиентское чат-приложение, реализованное на Java. Проект состоит из серверной и клиентской частей, которые позволяют нескольким пользователям подключаться и обмениваться сообщениями в реальном времени. Сервер пересылает сообщения всем подключенным клиентам, а пользователи могут выйти из чата, введя команду "exit".

Возможности:

Поддержка нескольких клиентов;

Передача сообщений в реальном времени;

Простой интерфейс командной строки;

Корректное завершение работы с командой "exit".

Использование:
1)Запустите класс Server на хост-машине.
2)На клиентской машине запустите класс Client, в SERVER_ADDRESS укажите айпи адрес сервера.
